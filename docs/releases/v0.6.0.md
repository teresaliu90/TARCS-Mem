# TARCS-Mem v0.6.0 — Open-source Preview

TARCS-Mem is a policy-first memory-governance layer for enterprise RAG and AI agents. This release focuses on a reproducible first-run path and on preventing stale, inaccessible, irrelevant or untraceable evidence from reaching generation.

## Highlights

- GuardWrite admission, bitemporal versioning, conflict resolution and human review.
- GuardRead hard ACL/status/time filters, hybrid retrieval, RRF, TARCS ranking and greedy budgeted MMR.
- Vector oversampling before governance filters to reduce false abstention.
- Local Ollama or DeepSeek cloud generation with enforced data-class egress policy.
- Missing/invented generated citations are blocked before output.
- FastAPI, Gradio, Qdrant, Docker, privacy-safe metrics, audit trails, rate limits and retry-safe writes.
- 120-query FiQA bounded-pool evaluation with four ablations and bootstrap intervals.
- Clean-wheel installation and CLI smoke-tested in CI on Python 3.11/3.12.

## Honest scope

This is an open-source reference implementation suitable for evaluation and a controlled pilot. Request-body roles are demo inputs. A production deployment must derive identity from OIDC/SSO, use a managed transactional store, externalize authorization, encrypt data and backups, scan uploads, export to SIEM/OTLP, and run domain-specific load, recovery and red-team tests.

The included FiQA experiment is a bounded candidate pool, not a full-corpus BEIR leaderboard result. The demo video records the v0.5 UI flow; v0.6 retrieval and production safeguards are verified by the release test suite and documentation.
