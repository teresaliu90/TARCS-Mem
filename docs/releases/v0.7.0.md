# TARCS-Mem v0.7.0 — Integration Release

This release turns the governance reference into a reusable integration layer
for existing agent and chat ecosystems.

## Highlights

- Official MCP Python SDK v2 server with stdio transport.
- Governed `search_trusted_memory` tool and a fail-safe memory proposal tool.
- Memory proposals are fixed to low-authority `user_claim` records and cannot
  self-promote to official policy.
- OpenAI-compatible `GET /v1/models` and non-streaming
  `POST /v1/chat/completions` endpoints.
- Client system messages cannot replace server-owned evidence, citation or
  cloud-egress policy.
- Native TARCS decision traces and citations remain available as response
  extension metadata.
- Native LangChain and LlamaIndex retrievers that expose only governed evidence.
- Confluence Cloud REST API v2 incremental synchronization with version/hash
  checkpoints, retry-safe IDs and conservative deletion handling.
- A new verified 85-second v0.7 walkthrough and 90 automated tests.
- In-memory MCP client protocol tests plus API, framework and connector regression tests.

## Honest scope

The compatibility endpoint implements the non-streaming chat-completions subset,
not every OpenAI API feature. Streaming is held back until citation verification
can remain fail-closed before response delivery. MCP tenant and role arguments
are local-demo attributes; production deployments must bind them to verified
OAuth/OIDC identity.
