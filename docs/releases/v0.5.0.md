# TARCS-Mem v0.5.0 — Evidence Release

This release turns the portfolio prototype into an evidence-backed open-source alpha.

## Highlights

- 120 real FiQA test queries and 610 candidate documents.
- Four retrieval ablations: lexical, hashed semantic, RRF, and complete TARCS.
- 1,000-sample deterministic bootstrap confidence intervals for every metric.
- TARCS Recall@10 `0.4446`, MRR@10 `0.4839`, NDCG@10 `0.3783`.
- Privacy-safe metrics/traces, tenant/role hard filters, credential blocking and PII redaction.
- 52 automated tests and an approximately two-minute Chinese demo video.

## Honest boundary

The FiQA experiment uses a bounded pool of qrel documents plus public distractors. It is not comparable to the full 57.6k-document BEIR leaderboard. The report includes the measured latency cost and does not hide weaker ablation results.

## Release assets

- Python wheel and source distribution.
- `fiqa-public-report.json` with aggregate metrics, confidence intervals and per-query hit flags.
- `tarcsmem-v0.5-demo.mp4` product walkthrough.
- `SHA256SUMS.txt` for every asset.
