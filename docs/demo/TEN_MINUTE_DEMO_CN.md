# TARCS-Mem v0.8 十分钟现场演示

> 演示状态：使用仓库内 6 条合成记录，不连接客户系统，不使用真实员工、制度或密钥。
> 目标不是展示“聊天更聪明”，而是让观众在十分钟内看懂写入边界、时间/版本、拒答、
> 引用和审计证据链。

## 演示前准备（不计入十分钟）

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[api]'
tarcsmem seed --db ./data/tarcsmem-demo.db --if-empty
tarcsmem serve --db ./data/tarcsmem-demo.db --port 8000
```

打开 `http://127.0.0.1:8000/console/`，浏览器缩放保持 100%。演示前运行
`./scripts/verify_quickstart.sh`，确认本机路径通过。不要在画面中展示 `.env`、终端历史、
真实 API Key 或客户数据。

## 三个必须说清楚的边界

1. **合成不等于真实试点。** 当前报告由维护者运行，没有客户、外部工程师或真实业务数据。
2. **SQLite 不等于不可篡改账本。** 页面必须保留 `chain_verified: false`。
3. **请求体角色不等于企业身份。** 生产必须由 OIDC/SSO 注入可信租户和角色，再接策略引擎。

## 现场失败时的安全退路

- 端口占用：改用 `--port 8001`，不要临场关闭未知进程。
- 页面无数据：确认 `seed` 和 `serve` 使用同一个数据库路径。
- API Key 提示：只在“集成中心”输入本次演示令牌，不展示令牌值。
- 无法联网：本演示无需联网；继续使用本地 FastAPI Console。
- 时间不足：保留“制度版本 → 证据链 → 拒答”三段，跳过连接器介绍。
